# 界面与工作区使用指南

[返回首页](../README.md) · [生成流程](FAULT_FIRST.md)

## 顶部导航

| 板块 | 路径 | 用途 |
| --- | --- | --- |
| 故障题目生成 | `/generate` | 输入需求、跟踪生成、恢复记录与作者审核 |
| 题库 | `/library` | 选题、开始训练与继续历史会话 |
| 个人工程项目训练 | `/projects` | 查看尚未开放的功能说明 |

任务详情、训练工作区与报告归属“题库”。路由支持深链接、刷新以及浏览器前进后退；生成详情归属“故障题目生成”。生成历史与训练历史使用统一的折叠列表，默认收起，展开后可查看或删除记录。品牌区域仅显示名称，切换板块请使用主导航。

## 训练工作区

左侧资源管理器分为任务文档、项目文件和测试资源。新训练默认只打开一个任务文档，集中展示只读题面、环境约束与可编辑诊断说明。公开测试与固定数据也在只读标签页中打开。只读文件有明确标识；多个文件可以同时打开，通过标签切换。关闭标签不会删除文件或未保存草稿。

工具栏显示是否有未保存修改。“保存”“保存并运行公开测试”“保存并提交评测”都会保存全部可编辑文件，包括当前未选中的文件。运行状态、失败详情和耗时显示在证据面板中。

对话区展示 Agent 回复与工具摘要，原始工具详情默认折叠。三级提示按需逐级获取，达到 L3 后显示“已获取全部提示”。报告中可查看提交代码和执行证据，模型反馈的生成状态单独显示。

窄屏使用任务、代码和对话面板切换。编辑较多模块时，建议使用桌面浏览器。

## 草稿与恢复

需求输入与训练草稿分别保存在当前浏览器；训练草稿按会话区分，避免跨会话覆盖。服务端保存的会话、生成记录和报告可以重新打开，生成任务不会因为页面卸载而取消。

浏览器草稿不是服务端备份。清理浏览器数据或更换浏览器之前，请先保存代码与诊断说明。

## 作者与学习者视图

作者审核页用于查看故障机制、参考修复和完整验证资产，包含答案信息。核对完成后，作者可使用右下方“添加至题库”，或暂不添加；缺少审核依据或确认勾选时会显示具体提示。未通过验证的任务不能入库，勾选审核确认本身不会发布题目。训练界面只显示题面、允许访问的文件与相应证据。准备独立练习时，应直接从题库进入训练。

## 记录管理

从题库移除任务会阻止新建该任务的训练，已有会话与报告仍保留。删除训练记录会将该会话及关联记录从正常查询中移除。执行删除前请阅读页面确认内容，必要时先备份数据目录。
